# IRAQI TIK Store

سورس متجر عراقي تيك: HTML + CSS + JavaScript، مع الصور والملف التعريفي PDF.
لا يحتاج npm أو تثبيت مكتبات أو خطوة Build.

## رفعه إلى GitHub
1. فك ضغط هذا الملف.
2. أنشئ مستودعًا مستقلاً للموقع، مثل iraqi-tik-store. لا تستخدم مستودع تحديثات التطبيق.
3. ارفع الملفات والمجلد assets إلى جذر المستودع، بحيث يكون index.html ظاهرًا في الصفحة الرئيسية للمستودع. لا ترفع ملف ZIP وحده.
4. لنشره عبر GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root) → Save، إذا كانت هذه الميزة متاحة في حسابك وإعدادات المستودع.
5. استعمل رابط الموقع الذي تعرضه GitHub بعد اكتمال النشر.

## أوامر Git
إذا كنت تعمل داخل نسخة مستودع مستنسخة على جهازك، انسخ هذه الملفات إلى جذرها ثم نفّذ:

```bash
git add -A
git commit -m "Add IRAQI TIK storefront"
git push origin main
```

## الملفات
- index.html: النصوص والأقسام والسعر وسياسة الاسترداد.
- style.css: التصميم الزجاجي البرغندي وتنسيق الهاتف.
- app.js: نوافذ عرض الصورة وتفاصيل الشراء.
- assets/: الصور وملف PDF.
- .nojekyll: تقديم الموقع كملفات ثابتة.

## الدفع
هذه واجهة متجر؛ الدفع الإلكتروني غير مفعّل بعد. زر الشراء يعرض تفاصيل الاشتراك وحالة تجهيز الدفع.
عند توفر رابط دفع، يمكن ربطه بالزر. عند استخدام API، تحفظ المفاتيح السرية في خادم مثل Cloudflare Worker، ولا توضع في هذه الملفات.
وسيلة الدعم وبيانات البائع الرسمية لم تُضف بعد؛ أضفها قبل إطلاق عمليات البيع.

## الرابط الحالي
تصدير هذا السورس لا يغير الموقع المنشور حاليًا ولا يوقف رابطه. انقل الرابط في بوابة الدفع فقط عندما تقرر الانتقال إلى الاستضافة الجديدة.
